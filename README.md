# React Calculator App

A simple calculator built with React, utilizing React hooks and custom UI components. This app supports basic arithmetic operations, sign toggling, percentage calculation, and decimal input.

## Features

- Perform addition, subtraction, multiplication, and division
- Clear input and reset calculator
- Toggle sign (+/-)
- Calculate percentages
- Input decimal numbers
- Responsive UI with custom button and card components

## Technologies Used

- React
- TypeScript
- Tailwind CSS (for styling)
- Custom UI components (`Button`, `Card`, `CardContent`)
- Utility functions (`cn` for classNames)
